# E-Commerce Sales Analysis using SQL

## Tools
- MySQL
- SQL

## Project Objective
Analyze e-commerce sales data and generate business insights.

## Database Tables
- Customers
- Products
- Orders

## Analysis Performed
1. Total Sales
2. Top 5 Products
3. Top Customers
4. Sales by Category
5. Sales by City
6. Monthly Sales
7. Customers Spending > ₹10,000
8. Most Ordered Products

## SQL Concepts Used
- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- LIMIT
- Date Functions

## Project Outcome
Analyzed e-commerce sales data to identify top products, high-value customers, sales by category and city, and monthly sales trends.
